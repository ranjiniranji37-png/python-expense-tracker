# Expense Tracker

A simple command-line Expense Tracker built with Python as part of the **Codomax Digital Solutions AI & ML Internship - Module 2 (Python Mini Project)**.

## Features
- Add expenses with title, category, amount and date
- View all expenses in a table
- Delete an expense
- Category-wise summary with percentages
- Data saved automatically in `expenses.json`
- Input validation and error handling

## Python Concepts Used
Variables, loops, functions, lists, dictionaries, file handling (JSON), exception handling, string formatting.

## How to Run
```bash
python expense_tracker.py
```

```

4. Summary by Category
```
